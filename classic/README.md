# Map Tools — Classic (v1)

เครื่องมือปักหมุดและวาดวงรัศมีเวอร์ชันแรก (Leaflet ไฟล์เดียว ไม่ต้อง build) นำกลับมาจาก commit `5f48235`
เพื่อใช้งานจริงระหว่างที่ v2 (ราก repo) ยังไม่ได้ deploy

URL หลัง merge (กรณี GitHub Pages ตั้งค่าเป็น Deploy from branch `main` / root):
<https://bokoboss.github.io/map-tools/classic/>

## ความสามารถเดิม (คงไว้ทั้งหมด)

- ปักหมุด กำหนดข้อความและสี ลากย้ายได้
- วงรัศมีหลายวงต่อหมุด แต่ละวงกำหนดระยะและสีแยกกัน
- วาดเส้น / รูปหลายเหลี่ยม / สี่เหลี่ยม / วงกลม พร้อมระยะทางและพื้นที่ (ตร.ม. และ ไร่-งาน-ตร.วา)
- ลูกศร ข้อความ และการหมุนข้อความ
- ค้นหาสถานที่ (Nominatim) แผนที่พื้นหลัง 7 แบบ เมนูคลิกขวา
- บันทึก/เปิดโปรเจกต์ `.json` และส่งออก `.png`

## สิ่งที่ปรับปรุงในรอบนี้

| เรื่อง | ก่อน | หลัง |
|---|---|---|
| บันทึก/เปิดไฟล์ | ข้อความหายหมด (เหลือแค่จุด), การหมุนหาย, หัวลูกศรกลายเป็นหมุดธรรมดา | เก็บครบทุกชนิด (ไฟล์รูปแบบ v2) และยังเปิดไฟล์รูปแบบเดิมได้ โดยจับคู่หัวลูกศรกลับคืนให้ |
| รูปทรงหลังเปิดไฟล์ | คลิกขวาไม่มีเมนู | มีเมนูแก้ไข/เปลี่ยนสี/ลบ เหมือนตอนวาดใหม่ |
| งานหายเมื่อรีเฟรช | ไม่มีการบันทึกอัตโนมัติ | บันทึกอัตโนมัติในเบราว์เซอร์ทุก 2 วินาที และกู้คืนเมื่อเปิดหน้าใหม่ |
| ข้อความจากผู้ใช้/ไฟล์/ผลค้นหา | แทรกเป็น HTML ตรงๆ | escape ก่อนแสดงผล |
| ค้นหาด้วยพิกัด | ช่องค้นหาบอกว่ารับพิกัดแต่ไม่รองรับจริง | วาง `13.7466, 100.5393` แล้วเปิดหน้าต่างเพิ่มหมุดที่พิกัดนั้นทันที |
| พิกัดในเมนูคลิกขวา | อ่านได้อย่างเดียว | คลิกเพื่อคัดลอก |
| วงรัศมี | รับค่า 0 ได้ | ต้องมากกว่า 0 และชี้ที่วงจะเห็นชื่อหมุดกับระยะ |
| อื่นๆ | — | Esc ยกเลิกเครื่องมือ/ปิดหน้าต่าง, เมนูคลิกขวาไม่ล้นขอบจอ, ชื่อไฟล์บันทึกมีวันเวลา, ลบ script `leaflet-geometryutil` ที่ URL ไม่มีอยู่จริง (404 มาตลอด) |

## ประเภทจุดสำรวจ

| ประเภท | รหัส | สัญลักษณ์ |
|---|---|---|
| แยกสัญญาณไฟ | TMC-xx | วงกลมแดง + ไฟจราจร |
| แยกไม่มีสัญญาณไฟ | TMC-xx (รันเลขต่อจากแยกสัญญาณไฟ) | วงกลมส้ม + เครื่องหมายบวก |
| จุดกลับรถ | UT-xx | วงกลมน้ำตาลทอง + ลูกศรกลับรถ |
| นับรถบนช่วงถนน | MB-xx | สี่เหลี่ยมน้ำเงิน + ลูกศรสองทาง |
| นับคนเดิน | PC-xx | สามเหลี่ยมเขียว + คนเดิน |
| จุดสำรวจ OD | OD-xx | หกเหลี่ยมม่วง + "OD" |
| หมุดทั่วไป | — | หมุดแบบเดิม เลือกสีเอง |

- รหัสเติมให้อัตโนมัติ (เลขถัดไปของรหัสนั้น) แก้เองได้ ระบบจำประเภทล่าสุดไว้สำหรับหมุดถัดไป
- คำอธิบายสัญลักษณ์แสดงมุมล่างซ้าย เฉพาะประเภทที่มีอยู่พร้อมจำนวนจุด ติดไปในภาพ PNG และซ่อนได้จากปุ่มในเครื่องมือหมุด
- ปุ่ม CSV ส่งออกรายการจุด (รหัส ประเภท ชื่อ ละติจูด ลองจิจูด รัศมี) เปิดใน Excel ภาษาไทยได้
- ไฟล์โปรเจกต์เดิมเปิดได้ตามปกติ หมุดเดิมจะเป็น "หมุดทั่วไป"

## การใช้งานเร็ว

- **ไม่บังคับชื่อ:** หมุดทุกประเภทบันทึกได้โดยไม่ใส่ชื่อ หมุดที่ไม่มีทั้งรหัสและชื่อจะไม่มีป้าย
- **ป้ายชื่อหมุด:** รหัส (ตัวหนา) + ชื่อ แสดงติดข้างสัญลักษณ์ตลอด และติดไปในภาพ PNG; ปุ่มรูปตาในเครื่องมือหมุดใช้ซ่อน/แสดง
- **ปักหมุดเร็ว (ปุ่มสายฟ้า):** เลือกประเภทในแถบด้านบน แล้วคลิกบนแผนที่ทีละจุด หมุดลงพร้อมรหัสถัดไปทันที กด "เสร็จ" หรือ Esc เพื่อออก
- **ย้อนกลับ / ทำซ้ำ:** Ctrl+Z / Ctrl+Y (หรือ Ctrl+Shift+Z) และปุ่มในเครื่องมือจัดการโปรเจกต์ ครอบคลุมการเพิ่ม ลบ ลาก แก้ไข และ "ลบข้อมูลทั้งหมด" (เก็บได้ 100 ขั้น เฉพาะในหน้าที่เปิดอยู่)

## ส่งออกภาพสำหรับรายงาน

- ปุ่มส่งออกภาพเปิดแผงตั้งค่าและกรอบกระดาษบนแผนที่ เลื่อน/ซูมแผนที่ให้พื้นที่อยู่ในกรอบ แล้วกด "ส่งออก PNG"
- ขนาด A4/A3 แนวนอนหรือแนวตั้ง ความละเอียด 150 / 200 / 300 dpi (A4 แนวนอน 200 dpi = 2339 × 1654 px)
- เลือกใส่ชื่อแผนที่ (พร้อมวันที่) ลูกศรทิศเหนือ มาตราส่วน คำอธิบายสัญลักษณ์ และป้ายชื่อหมุด
- "ตามหน้าจอ" คือการส่งออกแบบเดิม
- ภาพขนาดกระดาษใช้ modern-screenshot (ให้เบราว์เซอร์วาดเอง) เพราะ html2canvas วางไอคอนและป้ายผิดตำแหน่งเมื่อขยายความละเอียด หากใช้ไม่ได้จะกลับไปใช้ html2canvas อัตโนมัติ
- แผนที่แสดงมาตราส่วนที่มุมขวาล่างตลอดเวลา

## นำเข้า / ส่งออกข้อมูลจุด

- **นำเข้า CSV:** เพิ่มจุดต่อจากที่มีอยู่ (กดย้อนกลับได้ทั้งชุด) อ่านหัวคอลัมน์ไทยหรืออังกฤษ: รหัส/code, ประเภท/type, ชื่อ/name, ละติจูด/lat, ลองจิจูด/lng/lon, รัศมี/radius (คั่นหลายค่าด้วย ;) รองรับคั่นด้วย , หรือ ; และไฟล์ที่ส่งออกจากแอปนี้เอง ถ้าไม่มีประเภทจะดูจากรหัส (TMC/UT/MB/PC/OD) แถวที่พิกัดไม่ถูกต้องจะถูกข้ามและแจ้งจำนวน
- **ส่งออก KML:** เปิดใน Google Earth / Google My Maps ได้ แยกโฟลเดอร์ตามประเภท สีหมุดตามประเภท วงรัศมีเป็นรูปวงกลม และรวมเส้น รูปหลายเหลี่ยม วงกลม ลูกศร ข้อความ

## แผนที่ vector (MapLibre)

- ในรายการแผนที่พื้นหลังมี "Vector · Liberty", "Vector · Positron" และ "Vector · Bright" จาก OpenFreeMap (ฟรี ไม่ต้องใช้ key)
- แสดงผ่าน maplibre-gl 5.24.1 + maplibre-gl-leaflet 0.1.4 ซ้อนใน Leaflet เครื่องมือทุกตัวใช้ได้เหมือนเดิม
- โหลดไลบรารีเฉพาะเมื่อเลือกแผนที่ vector ครั้งแรก หน้าเว็บปกติไม่ช้าลง
- ชื่อสถานที่แสดงเป็นภาษาไทย (name:th ถ้าไม่มีใช้ชื่อท้องถิ่น) แทนแบบอังกฤษ+ไทยสองบรรทัด
- ตอนส่งออกขนาดกระดาษ แผนที่ vector จะวาดใหม่ที่ความละเอียดของภาพ ตัวหนังสือบนแผนที่จึงคมเท่ากับสัญลักษณ์และป้ายของเรา

## ข้อจำกัดที่ยังมีอยู่

- ใช้ CDN (รวม Tailwind Play CDN) ต้องต่ออินเทอร์เน็ต
- ภาพ PNG: บางแผนที่พื้นหลังอาจไม่ติดในภาพเพราะนโยบาย CORS ของผู้ให้บริการ และแผนที่พื้นหลังแบบ raster ที่ความละเอียดสูงเป็นการขยายจาก tile ปกติ (ตัวหนังสือบนแผนที่จะนุ่มกว่า) ถ้าต้องการภาพคมให้ใช้แผนที่ vector
- แผนที่ vector ต้องใช้ WebGL; เครื่องที่ไม่รองรับให้ใช้แผนที่ raster เดิม
- ผลวัดระยะ/พื้นที่ใช้สำหรับวางแผนเบื้องต้น ไม่ใช่งานรังวัด
